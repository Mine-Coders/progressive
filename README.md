## Importing
1. Wait for project to be imported by IntelliJ IDEA
2. Open the Gradle tools via the elephant button in the right sidebar towards the top
3. Under Tasks → fabric run the genSources task
4. Once that finishes when you open up a minecraft decompiled class, click choose sources and select the jar that has -sources at the end
